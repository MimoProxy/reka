# Mimo Reka for macOS

沿用 Mimo 的界面与交互，以 Reka 为唯一代理内核的独立 macOS 客户端。最低 macOS 14。

## 构建与打包

在仓库根目录运行：

```sh
./clients/mimo-reka/script/build_and_run.sh
./clients/mimo-reka/script/build_and_run.sh --package
```

产物：`clients/mimo-reka/dist/Mimo Reka.app` 和同目录 ZIP。构建优先使用 Xcode 工具链，不修改全局 `xcode-select`。Yams 源码随项目附带，构建不需要下载依赖；从当前工作区源码以锁定依赖、正式构建参数生成本机架构内核，记录内核提交、源码 SHA-256 和许可证；可用 REKA_KERNEL_PATH 显式指定已验证内核。试用包使用本地 ad-hoc 签名，未公证。

## 原子切换配置档案

配置页“使用”由同一个 Reka 进程完成：先校验目标档案并预备监听、路由和 DNS，再提交档案指针。成功切档不会重启内核，保留当前网络接管模式；新连接使用目标规则，已有连接继续使用原出口；接管参数改变时可能重建 TUN 并中断相关连接。目标档案必须支持当前接管模式，监听端口冲突、无效配置或资源缺失会拒绝切换，原档案继续运行。

各档案独立保存四层配置、选组、配置修订、订阅定义与缓存、资源更新设置。旧档案的订阅任务在切档前取消并等待退出，控制请求携带档案 ID 和切换代次，避免跨档写入。内核持久化最后确认的档案，客户端异常退出后以它为准恢复。流量累计、连接和 Fake IP 映射属于本次运行时，切档不清零；冷启动仍保持网络接管关闭。

首次从普通会话进入管理员运行时仍需一次授权和重启；迁移在停止刷新任务后读取完整历史，旧用户目录保留。进入管理员会话后，其他用户态档案的历史和资源先导入其独立的受保护目录，再原子切换，不再创建另一内核。已存在的受保护历史不会被覆盖。当前运行时的初始档案和 Fake IP/恢复日志所在档案须停止内核后才能删除。

## 进程、套餐与完整备份

连接页的“进程识别”可选关闭、按规则需要、所有新连接；默认按规则需要以保持原配置语义。选择“所有新连接”后，新连接主动显示可执行路径、可用的 PID/UID；“应用流量”按路径和用户汇总本次内核运行的累计字节，连接关闭后保留。最多记录 1024 个具体身份，未知和超限单独归类，重启清零。

订阅卡片显示服务方 Subscription-Userinfo 声明的用量、剩余和到期时间。缺失值显示未提供，零值不推断无限套餐，刷新失败保留上次成功数据并标记；这些数值与本机连接流量分别统计。

配置菜单或设置“配置与数据”可打开“完整备份与恢复”。备份包含四层配置、选组、来源名称和引用资源（客户端最多 128 个/512 MiB）；文件含内联凭据，以 0600 权限保存。secret:// 仅备份引用，需要原钥匙串或另行补充秘密值。恢复经一次确认后自动校验资源摘要和配置，网络接管保持关闭；端口冲突会拒绝提交并保留当前配置。

## 规则集与地理数据库

侧栏“规则集与数据库”统一管理本地文件和 URL 资源；规则页菜单也可直接打开同一界面。域名/IP/经典规则支持 text、yaml，域名和 IP 还支持 mrs。完整 GeoIP 支持 DAT/MMDB，GeoSite 支持 DAT，ASN 支持 MaxMind ASN MMDB。来源规则集随原来源更新，单独显示，避免混淆。

GeoIP/GeoSite/ASN 的默认下载地址沿用 Mimo 的 `https://testingcf.jsdelivr.net/gh/MetaCubeX/meta-rules-dat@release/`，文件分别为 `geoip.dat`、`geosite.dat`、`GeoLite2-ASN.mmdb`；GeoIP 改用 MMDB 时默认文件为 `country.mmdb`。可自定义 URL。下载到临时文件后按 1 MiB 分块上传、校验并以版本化事务替换；损坏、下载失败或配置冲突均保留原版本。自动更新在客户端和内核运行时检查，默认每天，可改为每小时、6 小时或每周，也可关闭并手动更新。ETag/Last-Modified 的 304 检查不产生配置修订；检查与错误状态独立持久保存。

单个资源上限由 16 MiB 调整为 128 MiB，资源总输入预算 384 MiB，备份和授权迁移合计 512 MiB；配置文档和控制帧仍有各自大小约束。授权迁移包含所有保留修订引用的资源，单份历史档案上限 128 MiB（原始文档合计 96 MiB），连同资源总计不超过 512 MiB；超过限制会保留原档案并提示处理。完整数据库以 `geodata` 保存，URL 与更新设置随四层配置一起备份；更新时间单独保存。

规则编辑器提供 `geoip`（国家代码或内置 LAN）、`geosite`（站点分类/属性）和 `ip-asn`（数字或 AS 前缀）条件。先下载对应数据库，再填写匹配值；保存会验证分类存在。IPv4/IPv6 都支持；IP 条件可选 no-resolve。Clash `IP-ASN` 转换也支持，但须明确绑定 ASN 数据库，导入不隐式读取 Mimo 的文件。

## 本轮新增

- 独立节点/策略 HTTP 延迟测试，自定义地址与超时，不改变选择。
- 本次内核运行累计流量和采样速率；重启按 epoch 重新采样。
- 规则、全局、直连路由模式；全局出口明确选择，保存时自动校验并生效。
- HTTP/TLS/QUIC 有界嗅探，连接详情显示嗅探域名、协议及可用的进程信息。
- 进程路径、通配符、UID、入口条件；路由解释与实际生效规则分页。
- DNS 分范围查询、清缓存与空闲连接重置，保留 Fake IP 映射；并发上游数和过期缓存设置。
- VLESS XHTTP、XMUX、独立下载端点、TLS/REALITY/ECH；监听认证用户。
- 结构化日志筛选，以及规则集/provider/GeoIP/GeoSite 文件上传、校验与引用。

所有会话以 `-defer-network` 待机启动，校验配置与持久化选组后保持接管关闭，由用户主动启用网络模式。上次未确认的网络提交不会在新会话自动执行，未知操作留档待核对。原本已关闭接管的错误配置仍提供控制接口供 GUI 修复。

## 独立运行

- 应用 ID：`org.mimoproxy.MimoReka`，进程为 `MimoReka` 与 `MimoRekaHost`。
- 配置目录：`~/Library/Application Support/MimoReka`，每份配置拥有独立来源、覆盖层和版本历史。
- 默认代理端口为 `127.0.0.1:17891`，首次创建配置遇到占用会使用空闲端口，界面显示实际地址。
- 初次启动只运行回环代理。系统代理和 TUN 需要在界面中主动启用；不会读取或改写原 Mimo 的工作区、Helper 或内核。
- 开启网络模式时由 macOS 请求管理员授权，运行独立的会话监督器，不安装 launchd 服务。管理员配置以 root 私有目录为准，控制 socket 仅向本机所属用户开放。

## 功能

仪表盘、多个配置档案、多来源导入、内核后台订阅刷新、策略与节点浏览、自动组健康状态、规则与 DNS、四层原生配置编辑、配置历史恢复、连接管理、内核日志，以及系统代理和增强模式入口。

可视化编辑入口：配置列表的“可视化编辑”打开监听、日志、DNS、Fake IP、来源引用和节点表单；代理页“+”新建策略，当前策略的“编辑”修改类型、成员、健康检查与顺序；规则页支持新增、修改、删除和上下移动。订阅节点、策略与规则的修改写入覆盖层，不改写来源快照。普通编辑只需点击“保存”，在一次操作中由内核自动校验并提交；失败保留编辑内容。规则排序直接保存，删除、替换主配置和恢复备份各保留一次确认。事务继续使用版本号、计划摘要和操作 ID，防止覆盖过时配置与重复提交。高级 YAML 入口继续保留，未在表单中展示的已有字段不会被清除。

来源卡片右上角的垃圾桶可删除本地来源或订阅（包括首次转换失败的空来源）。删除先确认，再通过一次版本化事务清理来源快照、主配置导入项、来源规则块、专属覆盖和策略组成员；手动选择若指向被删成员则使用剩余首个成员，组内已无成员时使用直连。仍被自定义规则、DNS 或路由设置引用时会拒绝删除，保持当前配置；其他来源与覆盖保留。应用不自动创建来源，首次订阅下载/转换失败的记录保留供重试或删除。

节点导入默认严格转换来源中的节点、策略与规则，也可以主动选择仅导入节点；无法转换的内容会阻止激活。原文中的 DNS 需要明确配置使用，不会静默替换本机解析策略。完整导入的来源规则优先匹配，应在其实际引用的策略组中选择节点。订阅刷新和选组均由 Reka 的版本化事务完成，失败保留旧版本。

仪表盘显示活动连接的上传与下载字节，进程内存使用 RSS；不将这些数据解释为累计流量、速率或真实物理内存。累计流量仅限本次内核运行，不提供跨会话历史流量；不展示 MITM、模块和 Tailscale 控件。

管理员授权会将四层配置、全部保留修订、操作记录、订阅缓存与历史引用资源复制到独立的 root 私有运行目录。已有 `secret://` 登录钥匙串引用不能直接迁移，应用会在停止原会话前明确拒绝。普通内联凭据配置可正常迁移；旧用户态版本仍保留为归档。网络授权配置后续启动需要重新授权。当前增强模式仅接管 IPv4，IPv6 不接管。

## 验证

```sh
MIMO_REKA_BIN_DIR="$(DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift build --package-path clients/mimo-reka --show-bin-path)"
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
MIMO_REKA_KERNEL_BINARY="$PWD/clients/mimo-reka/.build/core/reka" \
MIMO_REKA_HOST_BINARY="$MIMO_REKA_BIN_DIR/MimoRekaHost" \
MIMO_REKA_LISTEN_PORT=0 \
xcrun swift test --package-path clients/mimo-reka
```

测试使用隔离状态与回环服务。`python3 clients/mimo-reka/script/test-session-host.py` 另外验证授权会话的资源迁移、认证停止与 GUI 崩溃清理；该测试专用编译开关不进入打包产物。网络接管验证应在确认现有 VPN/代理归属后进行，普通构建和测试不会开启它们。

本地开发支持 `MIMO_REKA_HOME` 覆盖应用数据根目录，`MIMO_REKA_PROOF_PATH` 导出本应用内容截图，`MIMO_REKA_APPEARANCE=light|dark` 和 `MIMO_REKA_MIN_WINDOW=1` 用于布局验收。
